# 품질관리 CBT 모의고사

브라우저에서 동작하는 객관식 CBT 연습 앱입니다. 서버·빌드 과정이 없는 정적 파일(HTML/JS)이며, PWA라서 아이폰·안드로이드 홈 화면에 앱처럼 설치하고 오프라인에서도 쓸 수 있습니다.

## 기능
- 전체 / 1~7주차 범위 선택, 문제 순서 무작위
- 4·5·7지선다 등 보기 개수 제한 없음
- 문제 이동 번호판, 경과 시간, 제출 후 점수와 오답 확인
- 라이트/다크 모드, 모바일 터치 대응, 오프라인 사용(Service Worker)

## 실행
정적 서버로 열어야 합니다. (파일을 더블클릭하면 문제 파일을 못 불러옵니다.)
```
python3 -m http.server 8000   # http://localhost:8000
```

## 배포 (GitHub Pages)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. Settings → Pages → Branch를 `main` / root로 지정합니다.
3. 발급된 `https://<아이디>.github.io/<저장소>/` 주소를 공유합니다.
4. 아이폰은 Safari에서 열고 공유 버튼 → **홈 화면에 추가**, 안드로이드는 Chrome 메뉴 → **앱 설치**.

## 문제 추가·수정
`questions.json`을 편집합니다. 정답 `a`는 1부터 시작합니다.
```json
{"q": "문제", "o": ["보기1", "보기2", "보기3"], "a": 2, "w": "a"}
```
`w`는 `a`(1~7주차) 또는 `b`(8~15주차)입니다. 보기는 2개 이상이면 되고, 번호 기호는 ⑦까지 지원합니다.

## 저작권 주의
`questions.json`은 수업 자료(영진전문대학교 창업품질경영실무)에서 정리한 문제입니다. 해당 자료는 수업 목적 외의 공개·공유가 금지되어 있으므로 **`.gitignore`에 넣어 두었고, 공개 저장소에는 `questions.sample.json`(예시 3문제)만 올라갑니다.** 문제 파일을 공개하지 말고 개인 기기나 비공개 저장소에서만 쓰세요. 공개 배포가 필요하면 직접 만든 문제로 `questions.json`을 채우세요.
